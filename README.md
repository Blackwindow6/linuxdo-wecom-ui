## 主要特性

- 162px 展开导航、304px 会话列表和 192px 群成员栏，对齐企业微信 5.x 浅色桌面布局。
- 左侧导航包含当前用户、消息、邮件、文档、日程、待办、会议、智能文档、智能总结、工作台、通讯录、微盘和高级功能。
- 聊天分组包含未读、@我、单聊、群聊、内部聊天、外部聊天和标记；未读数量随真实话题列表同步。
- 会话列表提供企业微信式搜索框、蓝色选中态、分类标签、未读角标、可拖拽宽度，以及单字 / 九宫格隐私头像。
- 搜索框完整重置原站 `input[type="search"]` 样式，避免出现浏览器原生粗边框。
- 聊天详情使用本人浅蓝气泡、对方灰色气泡、置顶消息、时间分隔、分类标签、点赞、楼层书签和指定楼层回复；本人消息悬浮工具栏支持编辑，编辑时可直接粘贴剪贴板图片并上传。
- 点击消息、置顶消息或群成员头像可打开 Linux DO 原版用户资料卡。
- 左侧头像菜单完整保留原版通知分类、书签、消息和个人页签交互，页签与列表链接按原站路由跳转。
- 聊天标题栏可打开 Linux DO 原版话题书签弹窗，支持收藏、命名、提醒和取消收藏，状态与原站实时同步。
- 群成员栏读取真实话题参与者，区分群主与普通成员；窄屏时自动隐藏。
- 底部按企业微信输入框直接回复：`Enter` 发送、`Shift + Enter` 换行；输入期间不启动原生编辑器，避免焦点和搜索弹窗干扰。
- 输入区接入 Discourse 官方表情面板，并支持点击图片 / 附件按钮、粘贴或拖拽图片；图片上传后作为图片消息发送。
- 发送后自动同步新楼层，并记住当前话题的阅读位置，下次从上次看到的楼层继续。
- 顶部水印按钮支持开关与自定义文字；聊天图片支持大图预览、25%～500% 鼠标滚轮缩放，并提供可见的缩放比例与关闭按钮。
- 会话栏“+”可展开原站话题导航；聊天区右上角可切换回原生页面。
- 支持浅色、深色和跟随系统三种颜色模式；配色参考企业微信官方深色模式，选择会保存在当前浏览器。
- 检测到 IDEA、飞书或钉钉主题脚本时自动避让。同一时间只启用一套 Linux DO 外观脚本。


## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）。
2. 打开 [`linuxdo-wecom.user.js`](linuxdo-wecom.user.js)。
3. 在 GitHub 页面点击 **Raw**，脚本管理器会弹出安装页。
4. 安装后刷新 `https://linux.do/`。脚本更新后请硬刷新一次。

Raw 安装入口：

```text
https://github.com/Blackwindow6/linuxdo-wecom-ui/raw/main/linuxdo-wecom.user.js
```

同一时间只启用一套 Linux DO 外观脚本。

## 操作说明

| 位置 | 操作 |
| --- | --- |
| 左侧头像 | 打开 Linux DO 原生通知与个人菜单 |
| 会话栏搜索 | 同步原站搜索并提交 |
| 会话栏“+” | 展开或收起原站话题导航 |
| 消息 / 未读 | 切换最新列表与未读列表 |
| 伪装头像按钮 | 把真实头像替换成单字 / 九宫格伪装 |
| 气泡点赞 / 回复 / 书签 / 编辑 | 点赞、收藏、指定回复当前楼层，或编辑本人消息 |
| 消息 / 置顶 / 群成员头像 | 打开 Linux DO 原版用户资料卡 |
| 顶部书签按钮 | 打开原版话题书签弹窗，收藏或编辑当前话题书签 |
| 顶部水印按钮 | 打开聊天背景水印设置 |
| 顶部刷新按钮 | 刷新当前话题 |
| 顶部外链图标 | 切换到 Linux DO 原生视图 |
| 左侧栏“深色模式/浅色模式” | 一键切换深色与浅色 |
| 左侧栏“外观设置” | 选择浅色、深色或跟随系统 |
| 底部输入区 | 直接输入并发送，Enter 发送、Shift+Enter 换行；可粘贴或拖拽图片 |
| 输入区表情按钮 | 打开 Discourse 官方表情面板，并在当前光标位置插入站点表情代码 |
| 输入区图片 / 附件按钮 | 选择图片并上传后插入消息 |
| 聊天图片 | 点击打开大图预览；滚轮向上放大、向下缩小；右上角“关闭”、点击遮罩和 `Esc` 均可退出 |

切换到原生视图后，页面右下角会显示悬浮按钮，可切回企业微信视图。
